# Last $100: Swipe to Rich
## 3.1 · 财富与代价 / Windows 局域网版

基于提供的 **3.1 工程和操作方式**继续修改，不是切换到后续版本的界面，也没有增加新模式。投资滑杆保留现有行为。

## 最快开始：电脑启动，手机输入地址

1. **完整解压 ZIP**，不要在压缩包内部直接运行程序。
2. 双击根目录的 **`Start-Last100.exe`**。面向 Windows 10 / 11 x64；无需安装 Python、Node 或 Go。
3. 程序自动打开电脑浏览器，同时在窗口列出类似 `http://192.168.1.25:8765/` 的地址。**以你电脑实际显示的地址为准**。
4. 手机连接同一个 Wi-Fi，在 Chrome / Edge / Safari 的地址栏输入该地址，注意使用 **http**，不是 https。
5. 保持电脑和程序窗口开启。首次点击游戏后，浏览器才允许播放音乐。

端口默认 8765，被其他程序占用时依次尝试至 8775；游戏已经运行时再次双击会打开现有服务。电脑的 `127.0.0.1` 地址不能拿到手机使用。

### 手机连接不上

- 检查电脑和手机是否处于同一 Wi-Fi / 子网；访客 Wi-Fi、AP 客户端隔离、部分公司网络会禁止设备互访。
- 程序可能列出多个网卡地址，选择实际 Wi-Fi 网卡，而不是 VPN 或虚拟机网卡。
- Windows 首次提示防火墙权限时，**只允许专用网络**。仅在可信家庭网络中使用。
- 确有需要时，运行同目录的 `Allow-Private-Network.cmd`，确认后会请求管理员权限。它只为此 EXE 添加 **专用网络、LocalSubnet、TCP 8765–8775** 的入站规则；不会关闭防火墙或放行公用网络。
- 不要做路由器端口转发，不要把服务公开到互联网。程序只提供当前游戏 HTML，不开放目录、上传、远程命令或其他本地文件。
- EXE 是本次编译的未签名程序，Windows 可能显示未知发行者。请在确认来源并愿意运行时才批准；也可检查源码后自行编译。不要关闭系统防护。

电脑独自游玩也可以直接打开 `index.html`，但正常保存更推荐启动器提供的网页地址。关闭窗口停止服务；电脑睡眠或断开网络后手机无法重新加载。

## 保存规则

- 使用原有 `upshift-save-v3` 存储键，自动兼容旧生活系统存档；旧休息记录会补齐账单结构，不重复扣费或重复体检。
- **电脑、手机、不同浏览器、不同网页地址各自保存，不会自动同步**。更换电脑 IP、端口，或从 file 地址改成 http 地址，会产生不同的浏览器存储空间。
- 可以用游戏菜单的导出 / 导入迁移存档。沿用原工程规则：手动导入标记为 TEST，不参与平台验分；本地仍可继续玩。
- 隐私模式、浏览器清理数据或不允许本地存储的预览器会影响保存。本作是客户端离线游戏，不承诺防改档、防改时钟或联网验真。

## 这一轮实际改动

### 越富越复杂，变穷也会退阶

使用 **当前总身家**，而不是历史最高纪录，判断机制、服务和区域是否可用。回落时隐藏高级常驻 UI、暂停不足门槛的已购服务；回升后恢复，不重复收费。最高纪录仅用于历史成绩。

| 当前总身家门槛 | 阶段 | 主要新增内容 |
|---|---|---|
| $0 | 生存 | 干净的投资、现金、体力界面 |
| $500 | 工薪 | 通行与沿途商品逐步开放 |
| $10,000 | 中产 | 社群交往、账单摘要 |
| $100,000 | 富裕 | 保镖、安保姿态、地区税回应、康复 |
| $1,000,000 | 大人物 | 多派系、合规风波、私人区域 |
| $10,000,000 | 私人资本 | 地区奢侈消费、延寿研究、管理费 |
| $100,000,000 | 寡头 | 工业特区、更高费用 |
| $1,000,000,000 | 主权宾客 | 主权区域、更昂贵消费 |
| $10,000,000,000 | 全球财阀 | 细胞更新计划 |
| $100,000,000,000 | 云端议席 | 云端区域与极高税压 |
| $1,000,000,000,000 | 不可触及 | 极限财富压力 |

路线无最终站，但并非数学上的无限：资金、身家与分数有 **9 万亿美元** 的整数安全上限。

### 强制休息账单与正确身家

**总身家＝现金＋持有资产、服装、商品的原购入价值＋尚未交割的本金。** 不使用历史峰值，不把已付费用重复加回，不把奢侈点或奢侈消费计作资产。

- 平时显示下次休息预估；最穷阶段放进原有体力说明，不增加额外常驻面板。主菜单可看逐项账单。
- 入休时锁定维护、地区税、保镖工资、管理费和转世减免；当前身家随实际扣款立即下降。
- 基础税率依阶段为 0%、0.2%、0.6%、1.5%、3.5%、6%、9%、13%、17%、22%、28%；区域另有倍率，总税率封顶 58%。都是虚构税制。
- 先完成事件再缴账单。**不能支付并保留至少一美分，即结束本局；没有公共救助。** 资产多但现金不足也可能结束。
- 估算不包含尚未触发的罚款、劫案和自选消费。合规奖励、拒税等选择会影响本期支付或后续关系。
- 付费后免费等待十分钟即可恢复，也可购买活动缩短计时；离线会继续恢复。

### 简单选择，不做任务管理面板

- 合规风波：三个连续选项，合规成本合计为事件起始身家的 4.5%，全部完成奖励 6%；任何一步拒绝罚 14%。
- 平民、科技、工业、议政署、地下帮派、资本公会：支持、协商、拒绝影响关系。好友可能回馈，敌对者可能冻结资金或报复。
- 地区议政署税款只进入账单一次；拒缴会移除本次税款并伤害关系。
- 三档保镖，以及谨慎 / 平衡 / 强硬姿态。劫案失败损失现金；地下暗杀失败直接结束人生。选项明确显示代价与躲避概率。
- 事件触发时保存随机数；多步进度、已结算结果、确认状态均保存。刷新不重抽、不重复扣钱或发奖励。

### 健康、死亡与转世

- 初始健康 5 格、衰退概率 0%；每次休息增加 1 个百分点，第一次体检为 1%。抽中仅减 1 格，健康归零死亡。
- 高财富康复恢复健康；延寿、细胞更新可降低风险，且费用随身家和使用次数增加。
- 六城各有三件当地奢侈消费，价格为 $100 万 / $1,000 万 / $1 亿，对应 8 / 35 / 150 奢侈点。需要更高身家才能购买，同一件每局一次。
- **奢侈消费没有现金回报，也不计入资产**。本局死亡或主动结束后，奢侈点一次性结入转世账户。
- 开始界面及主菜单都有转世事务所；机制解锁下局生效，皮肤可立即换。每次结束保存死因、休息次数、峰值与奢侈点到本机人生榜。

### 场景、布局与保留内容

- 人物实际走两段垂直路径进入另一条街，镜头同步转动；持续保留周边街区，不再只剩孤立当前地块。转弯后项目、人物和招牌朝向同步调整。
- 场景和操作区各自占位，不互相覆盖。电脑版休息活动在左下；手机采用下方可滚动面板。小屏保留可见的前进 / 投资按钮。
- 项目文化说明在项目旁，手机上位于场景附近，可展开 / 收起。
- 主菜单调整 75%–125% 面板比例、14–22px 文字；财富配色与贴图可关闭。富裕界面逐级更华丽，最穷阶段没有额外常驻机制面板。
- 投资滑杆不恢复、不反向、不替换，保留已确认的现有行为。
- 200 起始体力，四次升级至 400；昼夜随体力变化。六城、点击世界地图、特殊街区的入场选择与工作任务继续保留，没有新模式。

## 源码构建

压缩包的 `source/` 是完整可编辑工程，不包含依赖目录。

```sh
npm ci
npm run build:production
npm test
```

成品生成于 `release-production/index.html`。构建需要 Node.js 20+；日常游玩不需要。

启动器在 `source/launcher/`，只使用 Go 标准库，Go 1.23+ 可构建：

```sh
cd launcher
go build -trimpath -ldflags="-s -w" -o Start-Last100.exe .
```

上面命令应在 Windows x64 执行；从其他系统交叉编译时设置 `GOOS=windows GOARCH=amd64`。把 EXE 与生成的 HTML 放到同一目录。`main_test.go` 检查局域网来源过滤，`go test .` 可运行。

浏览器回归使用 `qa/browser.mjs`，先运行本地服务于 8765，再安装 Playwright Chromium 及其系统依赖。`qa/world-check.mjs` 会生成独立测试场景，生产游戏不包含 QA 入口；`qa/final-check.mjs` 检查当前成品和只读服务。
